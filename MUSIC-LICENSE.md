# Music licensing

Music retrieved through the MCW Music API is composed by **Matthew C. Wright** and is supplied under **Creative Commons Attribution 4.0 (CC BY 4.0)** unless you separately obtain a different license for that song.

Read the [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/). Include the track's supplied `attribution` in your published project's description or credits, and identify edits such as trimming, fading, mixing, or looping.

Example credit:

```text
Music: "Nebula" by Matthew C. Wright
Licensed under Creative Commons Attribution 4.0
https://creativecommons.org/licenses/by/4.0/
Source: https://matthewcwright.com/music/royalty-free/000073-nebula/
Changes: Trimmed and faded beneath dialogue.
```

Use the actual attribution from your track response and describe only edits you actually made.

No-attribution licenses are available for **$49 per song** through [the music catalog](https://matthewcwright.com/music/royalty-free/). API access alone does not grant a no-attribution license.

The MIT license in this repository covers its example code and repository documentation. It does not license the music, recordings, composer branding, or third-party tools linked from this repository. Each track response includes its music license and source URL.
